# Release audit skill
1. Enumerate requirements in docs/ACCEPTANCE.md and run tests for each; no fabricated results.
2. Verify fresh setup and local server with actual commands; record platform.
3. Try two users and anonymous incognito; revoke/expire public link.
4. Check phone width, keyboard navigation, script escaping, bad file, no-data state.
5. Update README from implementation, <=2-page explanation; document real time, cuts and observed AI error.
6. Follow docs/DEMO.md to record genuine behavior, then prepare actual links for submission.
7. Stop at timebox and report limitations, never mark failed tests passed.
